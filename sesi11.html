2

Apa Itu Basis Data?

Basis data (database) adalah kumpulan data yang saling berhubungan, disimpan secara terstruktur, dan dapat diakses, dikelola, serta diperbarui dengan mudah. Contohnya daftar mahasiswa pada sistem akademik, katalog produk toko daring, atau daftar kontak pada ponsel.

Data

Fakta mentah yang belum diolah, misalnya angka, nama, atau tanggal.

Informasi

Data yang sudah diolah sehingga bermakna, misalnya rata-rata nilai satu kelas.

Basis Data

Tempat data disimpan terstruktur agar dapat diolah menjadi informasi.

Mengapa Tidak Cukup dengan Berkas Biasa? Bila data tersebar di banyak berkas terpisah, data yang sama bisa tersimpan berulang (redundansi) dan berbeda isinya (tidak konsisten). Basis data dirancang untuk mengurangi masalah tersebut.
3

Sistem Manajemen Basis Data (DBMS)

DBMS (database management system) adalah perangkat lunak yang menjadi perantara antara pengguna atau aplikasi dengan basis data. Pengguna tidak perlu mengetahui bagaimana data disimpan di dalam berkas.

Mengelola Data

Menyimpan, Mengambil, Mengubah, dan Menghapus

DBMS menyediakan cara untuk menambah, mencari, memperbarui, dan menghapus data, umumnya memakai bahasa kueri seperti SQL.

Menjaga Data

Keamanan, Integritas, dan Pemulihan

DBMS mengatur hak akses pengguna, menjaga agar data tetap sah dan konsisten, serta menyediakan cadangan (backup) dan pemulihan bila terjadi kerusakan.

Melayani Banyak Pengguna

Akses Bersamaan

DBMS memungkinkan banyak pengguna mengakses data yang sama pada waktu bersamaan tanpa saling merusak data.

4

Model Data Relasional

Pada model relasional, data disimpan dalam tabel. Setiap tabel terdiri atas baris (record) yang mewakili satu data, dan kolom (field) yang mewakili satu atribut. Tabel-tabel dapat dihubungkan lewat kunci.

Primary Key
Kolom (atau gabungan kolom) yang nilainya unik dan menjadi identitas tiap baris, misalnya NIM pada tabel mahasiswa.
Foreign Key
Kolom yang merujuk ke primary key tabel lain sehingga dua tabel dapat dihubungkan.

Contoh: tabel Mahasiswa dan tabel Pendaftaran Mata Kuliah dihubungkan oleh kolom NIM.

Mengenal SQL SQL (Structured Query Language) adalah bahasa untuk mengelola dan menanyakan data pada basis data relasional. Contoh kueri sederhana: SELECT Nama FROM Mahasiswa WHERE Prodi = 'Informatika'; untuk menampilkan nama mahasiswa program studi Informatika.
5

Pengantar Big Data

Big data adalah kumpulan data yang sangat besar, tumbuh cepat, dan beragam bentuk sehingga sulit dikelola dengan cara dan alat basis data biasa. Data ini dihasilkan, misalnya, oleh media sosial, transaksi daring, sensor, dan perangkat ponsel.

KarakteristikPenjelasan
VolumeJumlah data sangat besar
VelocityData bertambah dan mengalir dengan sangat cepat
VarietyBentuk data beragam: terstruktur (tabel), semi-terstruktur, dan tidak terstruktur (teks, gambar, video)

Selain tiga karakteristik di atas, sering ditambahkan veracity (tingkat kebenaran data) dan value (nilai guna data bagi keputusan). Pemanfaatan big data antara lain rekomendasi produk, analisis perilaku pelanggan, prakiraan cuaca, dan deteksi penipuan.

Perlu Diperhatikan Data dalam jumlah besar sering memuat data pribadi. Pengelolaannya perlu memperhatikan keamanan dan privasi, sebagaimana dibahas pada Sesi 5.
6

Glosarium Singkat

Basis Data
Kumpulan data terstruktur yang saling berhubungan dan mudah dikelola.
DBMS
Perangkat lunak untuk membuat, mengelola, dan mengendalikan akses ke basis data.
Record / Field
Baris data / kolom atribut dalam sebuah tabel.
SQL
Bahasa standar untuk mengelola dan menanyakan data pada basis data relasional.
Big Data
Data dalam volume besar, bertambah cepat, dan beragam bentuk.
