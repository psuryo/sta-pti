Lisensi & Jenis Software

"Gratis" dan "boleh dipakai bebas" adalah dua hal yang berbeda — memahami lisensi software melindungi Anda dari masalah hukum maupun keamanan.

Estimasi baca: 10–12 menit Ref: Discovering Computers, Modul 4
1

Mengapa Lisensi Software Penting?

Lisensi software adalah perjanjian hukum yang menentukan apa yang boleh dan tidak boleh dilakukan pengguna terhadap suatu software — mulai dari sekadar menggunakannya, hingga memodifikasi dan mendistribusikan ulang kode sumbernya.

Sebagian besar pengguna melewati begitu saja layar "Saya setuju dengan syarat & ketentuan" (EULA — End User License Agreement) tanpa membacanya. Padahal di sanalah aturan penggunaan software yang sah dijelaskan.

2

Jenis-Jenis Lisensi Software

Berbayar, Kode Tertutup

Proprietary / Commercial Software

Dibeli dengan lisensi resmi (sekali beli atau langganan). Kode sumber tertutup — pengguna hanya boleh menggunakan sesuai izin yang diberikan, tidak boleh memodifikasi atau mendistribusikan ulang.

Contoh: Microsoft Office, Adobe Photoshop (berlangganan).
Gratis dengan Batasan Fitur

Freemium

Versi dasar gratis untuk menarik pengguna, sementara fitur lanjutan (penyimpanan lebih besar, tanpa iklan, kolaborasi tim) memerlukan pembayaran berlangganan.

Contoh: Spotify (gratis dengan iklan vs Premium), Canva (gratis vs Pro).
Gratis Sepenuhnya, Kode Tertutup

Freeware

Bisa digunakan tanpa biaya, namun kode sumber tetap tertutup dan pengguna tidak diberi hak untuk memodifikasi atau mendistribusikan ulang programnya.

Contoh: beberapa aplikasi pembaca PDF gratis, sebagian browser.
Coba Dulu, Bayar Nanti

Shareware

Bisa dicoba gratis untuk periode/fitur terbatas, dengan harapan pengguna membeli lisensi penuh jika ingin terus memakainya.

Contoh: banyak software trial 30 hari sebelum meminta pembelian lisensi.
Kode Terbuka, Bisa Dimodifikasi

Open Source

Kode sumber dibuka untuk umum — siapa pun boleh melihat, memodifikasi, dan mendistribusikan ulang, selama mengikuti ketentuan lisensi yang menyertainya (mis. tetap mencantumkan lisensi yang sama saat didistribusikan ulang).

Contoh: LibreOffice, GIMP, sistem operasi Linux.

Risiko Software Bajakan/Ilegal

Menggunakan software bajakan (crack) bukan hanya masalah hukum, tapi juga risiko keamanan nyata:

  • Pelanggaran hukum hak cipta — di Indonesia, pembajakan software dapat dikenai sanksi berdasarkan UU Hak Cipta.
  • Tidak ada dukungan resmi — tidak bisa mendapat update keamanan atau bantuan teknis dari pembuat software.
  • Rentan disusupi malware — file crack sering menjadi media penyisipan virus, spyware, atau ransomware.
  • Ketidakstabilan sistem — software bajakan sering dimodifikasi secara tidak resmi sehingga rentan error atau konflik sistem.
Perlu Diwaspadai Sebagai mahasiswa, manfaatkan alternatif resmi dan gratis — banyak software premium punya versi gratis untuk pelajar/mahasiswa (education license) atau alternatif open source dengan fungsi setara.
5

Pertanyaan Reflektif

  • Coba cek software di laptop Anda — mana yang berlisensi resmi, freemium, atau mungkin bajakan tanpa Anda sadari?
  • Pernahkah Anda membaca EULA/syarat & ketentuan sebelum menginstal software? Mengapa kebanyakan orang melewatkannya?
  • Apa alternatif open source atau versi edukasi gratis yang bisa menggantikan software berbayar yang biasa Anda pakai?

Ringkasan Singkat

Lisensi software menentukan biaya, akses kode sumber, dan hak modifikasi — mulai dari proprietary (tertutup, berbayar) hingga open source (terbuka, bisa dimodifikasi). Software bajakan membawa risiko hukum dan keamanan nyata; sebagai mahasiswa, manfaatkan lisensi edukasi resmi atau alternatif open source sebagai pilihan yang lebih aman.
