Input dan Output

Panduan referensi untuk pertemuan keenam: mengenal ragam cara komputer menerima perintah dari kita (input) dan menyampaikan hasilnya kembali (output).

Perangkat Input

Perangkat input adalah perangkat keras yang digunakan untuk memasukkan data atau perintah ke dalam komputer.

Input Teks & Perintah Dasar

Keyboard

Perangkat input paling umum untuk mengetik teks dan memasukkan perintah. Selain keyboard fisik, kini juga umum keyboard virtual di layar sentuh.

Navigasi & Penunjuk Layar

Pointing Device

Perangkat untuk mengendalikan penunjuk (kursor) di layar — mencakup mouse, trackpad, trackball, dan layar sentuh (touchscreen).

Menangkap Kondisi Lingkungan

Sensor

Perangkat yang mendeteksi dan mengukur kondisi fisik di sekitarnya (cahaya, gerakan, suhu, lokasi) lalu mengubahnya menjadi data digital. Sensor kini tertanam di hampir semua perangkat mobile dan smart device.

Verifikasi Berbasis Tubuh

Biometrik

Perangkat input yang membaca karakteristik fisik unik pengguna untuk keperluan identifikasi/autentikasi — sidik jari, wajah, atau suara — sering dipakai bersama konsep autentikasi yang dibahas di Sesi 5.

3

Perangkat Output

Perangkat output menyampaikan hasil pemrosesan komputer kembali kepada pengguna, dalam bentuk yang bisa dilihat, didengar, atau dicetak.

JenisFungsiContoh
Layar (Display)Menampilkan output visual secara real-timeMonitor, layar laptop, proyektor
PrinterMencetak output ke media fisik (kertas)Printer inkjet, laser, 3D printer
AudioMenghasilkan output berupa suaraSpeaker, headphone, earphone
Poin Kunci Beberapa perangkat modern menggabungkan fungsi input dan output sekaligus — layar sentuh adalah contoh paling jelas: menampilkan output visual sekaligus menerima input sentuhan pengguna.
4

Tren Perangkat Input/Output

  • Kontrol suara — asisten virtual memungkinkan input tanpa sentuhan sama sekali.
  • Gesture & motion sensing — kamera dan sensor gerak sebagai input tanpa kontak fisik.
  • Haptic feedback — output berupa getaran/sentuhan untuk memberi umpan balik fisik (mis. saat mengetik di layar sentuh).
  • Layar fleksibel & lipat — perkembangan teknologi output visual yang makin portabel.
5

Glosarium Singkat

Pointing Device
Perangkat input untuk mengendalikan kursor di layar (mouse, trackpad, touchscreen).
Sensor
Perangkat yang mendeteksi kondisi fisik lingkungan dan mengubahnya menjadi data digital.
Biometrik
Metode identifikasi berdasarkan karakteristik fisik unik seseorang (sidik jari, wajah, suara).
Haptic Feedback
Umpan balik berupa getaran/sentuhan fisik dari suatu perangkat.
Touchscreen
Layar yang berfungsi ganda sebagai perangkat input (sentuhan) dan output (tampilan visual).
6

Cek Pemahaman Mandiri

  • Saya dapat menyebutkan minimal tiga jenis perangkat input beserta contohnya.
  • Saya dapat menyebutkan minimal tiga jenis perangkat output beserta contohnya.
  • Saya dapat menjelaskan perbedaan sensor dan biometrik sebagai perangkat input.
  • Saya dapat memberi contoh perangkat yang berfungsi sebagai input sekaligus output.
