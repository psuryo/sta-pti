Bagaimana Halaman Web Bekerja?

Saat Anda mengetik alamat situs di browser, browser meminta halaman itu kepada sebuah komputer server. Server mengirim berkas halaman, lalu browser menampilkannya sebagai halaman yang Anda lihat.

Browser

Aplikasi di perangkat Anda yang meminta dan menampilkan halaman web.

Web Server

Komputer yang menyimpan berkas situs dan mengirimkannya saat diminta.

URL

Alamat sebuah halaman, misalnya https://contoh.com/halaman.html.

Pengembangan web umumnya dibagi menjadi dua sisi: front-end (bagian yang dilihat dan dipakai pengunjung di browser) dan back-end (pengolahan di server, misalnya memproses pesanan dan mengakses basis data seperti pada Sesi 11). Sesi ini berfokus pada front-end dasar: HTML dan CSS.

Hubungan dengan Materi Sebelumnya Pengiriman halaman memakai jaringan dan alamat IP (Sesi 10), dan alamat berbentuk nama diterjemahkan oleh DNS. Halaman yang memuat data pengguna biasanya mengambilnya dari basis data (Sesi 11).
3

HTML: Struktur Halaman

HTML (HyperText Markup Language) adalah bahasa penanda yang menyusun isi halaman: judul, paragraf, gambar, tautan, dan daftar. Isi dibungkus oleh tag, umumnya berpasangan seperti <p>...</p>.

Contoh halaman HTML paling sederhana:

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Halaman Pertamaku</title>
</head>
<body>
  <h1>Halo, Dunia!</h1>
  <p>Ini halaman web pertama saya.</p>
  <a href="https://contoh.com">Kunjungi contoh</a>
</body>
</html>
TagFungsi
<head>Informasi tentang halaman (judul pada tab browser, pengaturan karakter). Tidak tampil sebagai isi halaman
<body>Seluruh isi yang tampil di halaman
<h1> sampai <h6>Judul dan sub judul, dari yang terbesar sampai terkecil
<p>Paragraf
<a href="...">Tautan ke halaman lain
<img src="..." alt="...">Gambar, dengan teks alternatif pada alt
<ul>, <ol>, <li>Daftar berpoin, daftar bernomor, dan butir daftar
4

CSS: Mengatur Tampilan

CSS (Cascading Style Sheets) mengatur tampilan: warna, huruf, jarak, dan tata letak. Dengan CSS, struktur isi (HTML) terpisah dari tampilannya.

Sebuah aturan CSS terdiri atas selector (bagian yang diberi gaya) dan deklarasi berupa pasangan properti dan nilai:

body {
  font-family: Arial, sans-serif;
  background-color: #f5f5f5;
}
h1 {
  color: teal;
  text-align: center;
}

Aturan di atas membuat seluruh halaman memakai huruf Arial dengan latar abu-abu muda, dan setiap <h1> berwarna hijau kebiruan serta berada di tengah.

Cara Memasang CSSKeterangan
InlineDitulis langsung pada tag melalui atribut style. Cepat, tetapi sulit dikelola
InternalDitulis di dalam tag <style> pada bagian <head> halaman
EksternalDitulis dalam berkas .css terpisah dan dipanggil dengan <link rel="stylesheet" href="gaya.css">. Paling rapi untuk situs dengan banyak halaman
5

Web Hosting dan Nama Domain

Halaman yang hanya ada di komputer Anda tidak dapat dibuka orang lain. Agar dapat diakses publik, situs perlu disimpan di server yang selalu menyala dan memiliki alamat yang mudah diingat.

Web Hosting

Tempat Menyimpan Situs

Layanan yang menyediakan ruang di server untuk menyimpan berkas situs dan melayani pengunjung. Penyedia ada yang gratis dan ada yang berbayar, dengan perbedaan pada kapasitas, kecepatan, dan dukungan.

Nama Domain

Alamat yang Mudah Diingat

Nama situs seperti contoh.com yang diterjemahkan oleh DNS menjadi alamat IP server. Nama domain didaftarkan melalui penyedia domain dengan biaya berkala. Akhiran seperti .com, .id, atau .ac.id disebut domain tingkat atas.

HTTPS

Koneksi yang Aman

HTTPS mengenkripsi data antara browser dan server sehingga tidak mudah disadap. Situs yang meminta data pengunjung (kata sandi, data pribadi) sebaiknya memakai HTTPS, sebagaimana dibahas pada Sesi 5.

Alur singkat mempublikasikan situs: membuat halaman, memilih penyedia hosting, mendaftarkan nama domain, mengunggah berkas ke hosting, lalu mengarahkan domain ke hosting tersebut.

Perlu Diperhatikan Syarat dan batas layanan hosting dan domain, termasuk yang gratis, sering berubah. Periksa ketentuan penyedia sebelum mendaftar dan jangan memasukkan data pribadi yang tidak perlu.
6

Mencoba Sendiri

  • Buat folder baru, lalu buat berkas index.html dengan editor teks (misalnya Notepad atau editor kode apa pun).
  • Salin contoh HTML di atas, ubah judul dan isinya, lalu simpan.
  • Buka berkas itu dengan browser (klik dua kali berkasnya).
  • Tambahkan aturan CSS pada bagian <head> memakai tag <style>, simpan, lalu muat ulang halaman untuk melihat perubahannya.
  • Tambahkan satu daftar berpoin dan satu tautan ke situs pilihan Anda.
7

Glosarium Singkat

HTML
Bahasa penanda yang menyusun isi dan struktur halaman web.
CSS
Bahasa aturan gaya untuk mengatur tampilan halaman web.
Tag
Penanda HTML, umumnya berpasangan (pembuka dan penutup), yang membungkus isi.
Front-end / Back-end
Bagian situs yang dilihat pengunjung di browser / pengolahan di server.
Web Hosting
Layanan penyimpanan berkas situs pada server yang dapat diakses publik.
Domain
Nama situs yang mudah diingat dan diterjemahkan oleh DNS menjadi alamat IP.

Cek Pemahaman Mandiri

  • Saya dapat menjelaskan peran browser, server, dan URL saat membuka sebuah halaman.
  • Saya dapat menulis halaman HTML sederhana dengan judul, paragraf, tautan, dan daftar.
  • Saya dapat menulis aturan CSS dasar dan menyebut tiga cara memasangnya.
  • Saya dapat membedakan web hosting dan nama domain serta menjelaskan peran DNS.
